## 🧠 Problem Statement

Customer churn is a critical business problem in subscription-based industries. Acquiring a new customer costs significantly more than retaining an existing one.

> ❓ **How can we predict which customers are likely to churn and proactively retain them?**

---
## 📌 Project Overview
Customer churn is one of the biggest challenges for subscription-based businesses. In this project, we analyze customer behavior and build machine learning models to predict churn and provide actionable retention strategies.

This project covers:
- Data cleaning & preprocessing  
- Exploratory Data Analysis (EDA)  
- Feature engineering  
- Machine learning model building  
- Model evaluation (ROC-AUC, classification metrics)  
- Business insights & recommendations  

## 🎯 Project Objectives

- 🔍 Predict customer churn using machine learning models  
- 📊 Identify key drivers influencing churn behavior  
- 💡 Provide actionable, data-driven retention strategies  
- 📈 Translate model insights into business impact  

---

## 🏆 Key Highlights

- ✅ Built an **end-to-end ML pipeline** from data cleaning to model evaluation  
- 📈 Achieved strong predictive performance using ensemble methods  
- 🔎 Identified high-risk customer segments

## 🔄 Project Workflow

### 1️⃣ Data Preprocessing
- Handled missing values and inconsistencies  
- Converted data types (`TotalCharges`)  
- Dropped non-informative columns (`customerID`)  
- Encoded categorical variables  


---

### 2️⃣ Exploratory Data Analysis (EDA)

Key patterns discovered:

- 📉 Month-to-month contracts show highest churn  
- 💰 Higher monthly charges correlate with churn  
- ⏳ Customers with low tenure churn more  


---

### 3️⃣ Feature Engineering

- Created **tenure groups**  
- Applied **one-hot encoding**  
- Improved model interpretability  

---

## 💡 Business Insights & Recommendations

### 🔴 High-Risk Customers
- Month-to-month subscribers  
- High monthly charges  
- New customers (low tenure)

### 🟢 Retention Strategies
- Offer discounts for long-term plans  
- Introduce loyalty programs  
- Improve onboarding experience  
- Provide personalized offers  

---

## 📈 Business Impact (Why This Matters)

- 📉 Reduce churn rate  
- 💰 Increase customer lifetime value (CLV)  
- 📊 Improve retention strategy targeting  
- ⚡ Enable proactive decision-making
